# GOVERNANCE

Как устроено управление **polymath-os**. Коротко: один владелец, решения через
ADR, слияние — только через защищённый конвейер, исполнитель — мультиагентный
рой под ответственностью владельца.

## Роли

| Роль                         | Кто                                      | Полномочия                                                                                          |
| ---------------------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Владелец (Хозяин)**        | [@rtynbirf](https://github.com/rtynbirf) | единоличное решение ADR, выпуск релизов, отзыв/выдача ключей, изменение законов                     |
| **Рой (агенты-исполнители)** | автоматические волны                     | коммиты в `main` по законам роя (см. `AGENTS.md`), воркфлоу, pulse — ответственность несёт владелец |
| **Вкладчики**                | внешние разработчики                     | PR в `main`: 2 approvals, линейная история, подписанные коммиты (см. `CONTRIBUTING.md`)             |

## Принятие решений

1. **Архитектура** — через ADR (`docs/adr/`, нумерованные, append-only;
   изменение поведения без ADR запрещено).
2. **Дорожная карта** — `ROADMAP.md` / `TODO.md`; приоритет задаёт владелец.
3. **Ритм** — пульс-аудит ПУЛЬС v2 по расписанию (понедельник 04:17 UTC,
   `PULSE.md` — журнал-из-фактов).
4. **Мультиагентные волны** — отчёты append-only в
   [`rtynbirf/github-runbook`](https://github.com/rtynbirf/github-runbook)
   (§-секции, чужие секции не трогаются, закрытие issues — только по живому
   зелёному прогону).

## Механика слияния

- `main` защищён: ruleset + классическая веточная защита (оба слоя).
- PR требует **2 approvals**, разрешение обсуждений, актуальность ветки,
  линейную историю, подписанные коммиты (SSH, required signatures).
- Admin-bypass (`enforce_admins=false`) — легальный канал бота-хранителя
  ритма (пульс, кровь роя); каждое использование видно в истории коммитов.
- Релизы **неизменяемы** (immutable releases): тег и ассеты залочены после
  публикации; аттестации релиза — Sigstore.

## Безопасность

- Политика раскрытия: `SECURITY.md`; приватный канал: PVR.
- Машиночитаемый отчёт: `security-insights.yml`.
- Токены: только env/secrets, ротация на мандат (реестр в `github-runbook`);
  ключи в чате считаются скомпрометированными.

## Изменение этого документа

Правки через ADR — как и любое изменение управления.
