1. Цвет вычисляется, а не выбирается

Вся страница окрашена из одного семени oklch(.52 .105 var(--hue)). Тени, акценты, ховеры выводятся относительным синтаксисом и color-mix() — комфорт наследуется автоматически.

oklch

Канал L здесь = реальная воспринимаемая яркость: светлые — светлые, тёмные — тёмные, без сюрпризов HSL.

color-mix()

Плашки .tag и фон кода — это color-mix(in oklch, acc 14%, bg): мягкий, приглушённый, не кричит.

2. Типографика дышит

Размеры заданы clamp() — строка плавно растёт от телефона до 4K. Абзацы получают text-wrap: pretty (нет «сирот»), заголовки — text-wrap: balance. Вот заголовок, который без balance ломался бы уродливо: Проверка баланса переносов в строке.

text-box-trim

Если браузер поддерживает text-box, воздух над этим текстом обрезан точно по кеглю. Таймер с tabular-nums не «пляшет»: 00:00:00

3. Движение только с meaningful-нагрузкой

Полоса сверху и появление секций — scroll-driven animations на композиторе браузера: ноль JS, ноль jank. Отключаются тумблером «Тишина», системным prefers-reduced-motion — автоматически.

View Transitions API

Смена содержимого через document.startViewTransition — плавный кросс-фейд средствами браузера.

linear() spring

Кнопки приподнимаются на пружинной кривой linear() — физика без JS-библиотек. Попробуй Tab-ом.

4. Нативные виджеты без JS-каркасов

<dialog>, Popover API, invoker commands, field-sizing — доступность из коробки браузера. Тултип ниже привязан к кнопке anchor positioning (Baseline 2026).

5. Производительность = спокойные глаза

Список из 300 пунктов ниже рендерится только у видимой части: content-visibility: auto + contain-intrinsic-size. Скролл ровный, без рывков — глазу не за что цепляться.

    6. Велнес-слой

    Фонарик. Включи тумблер в шапке: активный абзац светлый, остальные приглушены — читается только то, куда смотрит внимание.

    Голосом. Устали глаза? Пусть страница читает вслух — Speech Synthesis, бесплатный отдых для зрения.

    E-ink режим — имитация электронных чернил (filter: grayscale(1)): ноль цветового возбуждения перед сном. Контраст+ повторяет системную настройку prefers-contrast: more.
