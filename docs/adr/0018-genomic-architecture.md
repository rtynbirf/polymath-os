# ADR-0018 — Genomic Architecture (holographic principle)

**Date:** 2026-10-16 (v2.7.0)
**Status:** Accepted
**Deciders:** @USER
**Supersedes:** None (extends ADR-0012)

## Context

The ХОЛОН project (shared chat) builds on "голархические" (holographic)
principles: each part contains a fingerprint of the whole. This is not
a new idea — it's the same principle that SINGULYAR EIR v0.3 already
implements: each Adapter carries the full contract (execute + read_state
→ Observation tri-state), so each part IS the whole at the contract level.

This ADR formalizes that principle as an architectural decision, so that
future adapters, modules, and repos in the rtynbirf ecosystem all follow it.

## Decision

### 1. Each part contains the contract of the whole

Every adapter in the SINGULYAR EIR kernel implements the same Adapter
contract:
- `execute(intent, idempotency_key) → Any`
- `read_state(intent, idempotency_key) → Observation(PRESENT|ABSENT|UNAVAILABLE)`
- `status() → {state, privacy, reason, ...}`
- `is_available() → bool`
- Declares `CAPABILITIES` tuple (Capability dataclass)

This means: any single adapter, taken alone, is a complete expression
of the kernel's contract. The kernel without adapters is a framework;
each adapter makes it a working system. This is the "genomic" property —
each cell carries the full DNA.

### 2. Each audit document carries the methodology of the whole

Every audit document (Level 1-5) uses the same finding format:
- что не так → почему важно → альтернатива → как проверить
- confidence labels: [док] / [вывод] / [проверить]

Any single audit document, taken alone, demonstrates the full methodology.
The methodology without audits is a template; each audit makes it a
working process. Genomic.

### 3. Each repo carries the rules of the whole

AGENTS.md + POLYMATH_PROTOCOL.md + SOVEREIGNTY_CONTRACT.md are present
in polymath-os. Singulyar has its own AGENTS.md with the 7 «Незыблемое»
laws. The rules differ in content but share the same structure: "what
the agent must know to work in this repo without breaking it."

Any single repo's AGENTS.md, taken alone, encodes the governance model.
The governance without repos is a principle; each repo's AGENTS.md makes
it a working contract. Genomic.

### 4. The holographic invariant

**Each part, when separated from the whole, still contains:**
1. The contract (what it does)
2. The methodology (how it's verified)
3. The rules (what it must not break)
4. The intent (whose purpose it serves)

This is the "holographic" or "genomic" property: the whole is in each
part, and each part is the whole at its level of abstraction.

## Consequences

- **+**: Any adapter can be extracted and used standalone (it carries
  the full contract). The bridge (subprocess_bridge.py) proves this —
  it wires ONE adapter (LLMLocalAdapter) and the kernel works.
- **+**: Any audit document can be applied to any project (it carries
  the full methodology). AUDIT_SINGULYAR was generated by applying
  AUDIT_POLYMATH's methodology to a different project.
- **+**: Any repo's AGENTS.md enables an AI session to work in that
  repo without prior context. The next session reads AGENTS.md and
  continues — fork-exec of the human's intent.
- **-**: The genomic property requires discipline — every new adapter
  must implement the full contract, not a subset. No "almost-adapter."
- **-**: Every new audit must use the same finding format. No ad-hoc
  audit style.

## Alternatives considered

1. **Monolithic architecture** — one big file/module that does everything.
   Rejected: violates ADR-0012 (each layer is separate) and the
   sovereignty principle (each part replaceable).
2. **Microservices without shared contract** — each service defines its
   own interface. Rejected: no genomic property — removing one service
   breaks the whole.
3. **Plugin architecture without contract** — plugins can do anything.
   Rejected: no falsifiability — can't verify that a plugin follows
   the contract without inspecting its code.

## Verification

- 3 real adapters (LLMLocal, HTTP, WebRTC) all implement the same
  Adapter contract → genomic property holds at adapter level ✅
- 5 audit documents (Level 1-5) all use the same finding format →
  genomic property holds at audit level ✅
- 2 repos (polymath-os + singulyar) have AGENTS.md → genomic property
  holds at repo level ✅
- The Python↔JS bridge wires ONE adapter and the kernel works →
  genomic property proven by extraction ✅
