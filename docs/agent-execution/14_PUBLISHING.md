# Публикация пакета в GitHub

Публикация выполняется в отдельную ветку и через pull request. Скрипт не читает PAT, не сохраняет credentials и использует уже настроенную локальную сессию GitHub CLI.

## Требования

- Git;
- GitHub CLI (`gh`);
- Python 3.10+;
- доступ к `rtynbirf/polymath-os` через локальный `gh auth login --web`.

## Запуск в Windows PowerShell

Сначала клонировать репозиторий и пройти web-login, если ещё не выполнено:

```powershell
gh auth login --web
gh repo clone rtynbirf/polymath-os
```

Из распакованного каталога пакета:

```powershell
.\tools\publish-to-github.ps1 -RepoPath "$HOME\polymath-os"
```

Скрипт проверяет origin, доступ к репозиторию, чистоту рабочей копии, отсутствие одноимённой удалённой ветки и конфликты файлов. Различающиеся существующие файлы не перезаписываются: операция останавливается до копирования. Затем выполняются валидатор, unit-тест, `git diff --check`, commit, push и создание PR.

## Ограничения

- Скрипт предназначен для ручного запуска владельцем репозитория в его локальной среде.
- Он не сливает PR и не меняет branch protection.
- Если `AGENTS.md` уже существует и отличается, потребуется осознанное объединение правил.
- Успешный push ветки не означает прохождение CI или принятие PR.
- При сетевой ошибке или недостатке прав скрипт завершится с ошибкой и не заявит об успешной публикации.
