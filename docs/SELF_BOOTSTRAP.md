## Honest disclosure

- **GitHub Pages site** (`https://rtynbirf.github.io/polymath-os/`) requires
  internet to view. The vault content is in `git clone` (offline-readable),
  but the public garden rendering is on GitHub's infrastructure (Tier 2).
- **Real LLM inference** requires downloading Qwen2.5-0.5B GGUF (~470 MB)
  from HuggingFace (Tier 2). The rule-layer fallback works offline.
- **Real WebRTC** requires `pip install aiortc` (Tier 2). The adapter
  contract is Tier 1 (works without aiortc — returns UNAVAILABLE).
- **SLSA L2 attestation** uses cosign keyless via GitHub Actions OIDC.
  Verification requires the Sigstore root of trust (Tier 2).

These Tier 2 dependencies are documented in `runtime/docs/LIMITATIONS.md`
and gated by ADR-0002 Sovereignty Registry. None is load-bearing for the
open-source contract (`make verify` + `cd runtime && python3 scripts/check.py`).
