# The Polymath OS Manifesto

**2026-10-16 · v2.5.0**

1. **Человек — PID=1.** Каждый инструмент — fork-exec от человека. Креды — per-process, не shared. Я наследую правила, не твою личность.

2. **PAROLE > LANGUE.** Индивидуальное слово выше коллективного договора. Договор — суррогат. Человек — сам себе пароль.

3. **UNKNOWN first-class.** Таймаут — не успех, не провал. Ядро не угадывает. Я не вру CONFIRMED.

4. **Default-deny.** Публикуется только явное `publish: true`. Канарейка в published output = deploy заблокирован.

5. **Make verify — закон.** 20 проверок. Если ≠0 — ничего не выходит. Нет зелёной галочки — нет релиза.

6. **Каждое утверждение — проверяемо.** Если `make verify` не может проверить — это риторика. Риторика удаляется.

7. **Суверенитет — свойство, не поза.** Tier 1 (offline) > Tier 2 (replaceable) > Tier 3 (closed). Еженедельный drill это доказывает.

8. **Аудит — рекурсивен.** Методология generic. Я могу аудитировать себя, свой продукт, свою экосистему — одним и тем же форматом.

9. **Намерение сохраняется через границы.** Через смену исполнителя. Через смену AI-сессии. Через границы репозиториев. Через языковые границы. Через концептуальные границы. Аудит → issue → ядро → GitAdapter → PR → MERGE.

10. **Совершенству нет предела.** Каждая итерация — `make verify` green, или не merge. Дисциплина enforced, не aspirational.
