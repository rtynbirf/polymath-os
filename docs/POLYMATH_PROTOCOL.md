## 5 законов

### 1. ЧЕЛОВЕК = PID=1
Человек — init-процесс. Каждый инструмент — fork-exec от человека. PAT/SSH
ключ — security context процесса, не образ. fork() копирует image, не creds.
См. ADR-0002 §3.7, ARCHITECTURE.md §1.

### 2. PAROLE > LANGUE
Индивидуальное слово выше коллективного договора. Договор (langue) —
суррогат живого слова (parole). Человек — сам себе пароль. Корпорации
и государства — нарезаны из человека, а не наоборот.
См. ARCHITECTURE.md §1 тезис 2.

### 3. LFS AS ETHICAL POSITION
Linux From Scratch как этическая позиция: никаких предсобранных бинарников,
никаких скрытых зависимостей. Суверенное ядро (Tier 1): git, markdown, SQLite,
age, Nix, Conventional Commits, cosign (keyless), CycloneDX, Python stdlib.
См. ADR-0002 Tier 1.

### 4. UNKNOWN IS FIRST-CLASS
Таймаут ≠ failure. Таймаут ≠ success. Таймаут = UNKNOWN. Ядро не угадывает.
Adapter возвращает Observation tri-state: PRESENT/ABSENT/UNAVAILABLE.
Verdict tri-state: PASS/FAIL/INCONCLUSIVE.
См. ADR-0006, runtime/docs/TECHNICAL_SPEC.md §4.

### 5. DEFAULT-DENY
Публикуется только явное `publish: true`. Канарейка (`__CANARY_p1m0s_8f3a2e91_dnp_v1__`)
в published output = deploy blocked. Git history не чистит `.gitignore`.
См. ADR-0009, apps/garden/scripts/filter_vault.py.

## 8 законов роя (multi-agent)

Per ADR-0007: research=parallel, execution=single+verifier.

### З.1 ОДИН КЛЮЧ НА ВОРОТ
Каждый push-tag = один release. `make verify` = единственный open-source
contract. Если не проходит — ничего не выходит.

### З.2 ДИРЕКТИВА 1 — ВСЁ ВПИСЫВАТЬ
Каждое архитектурное решение → ADR. Каждая зависимость → Sovereignty
Registry. Каждый pattern → CI check. Ничего в голове.

### З.3 ДИРЕКТИВА 2 — СТРОГО ПО ПОРЯДКУ
Новый ADR → AUDIT_RESPONSE.md row → make verify check 05 проходит.
Новый адаптер → тесты → S15 test → check.py проходит.

### З.4 ЛЕТОПИСЬ APPEND-ONLY
`runtime/SHA256SUMS.txt` + `runtime/docs/TEST_REPORT.md` regenerated by
`scripts/check.py`. CHANGELOG.md — Keep a Changelog v1.1.0. Git history
immutable (per ADR-0016).

### З.5 БАЙТЫ КОЛЛЕГ НЕ ТРОГАТЬ
Merge queue + squash-merge. Linear history required. Force-pushes forbidden.
Stale PRs auto-close after 30 days (Dependabot).

### З.6 СТОП-ГОРН
`make verify` красный = стоп. Не пушить. Не релизить. Не закрывать issue.
Чинить, потом продолжать.

### З.7 ТОЛЬКО ИЗМЕРЕННЫЕ ЦИФРЫ
"86 tests" — из `python3 scripts/check.py`. "20 checks" — из `make verify`.
"5 agents, 0 duplicates" — из `multi_agent_demo.py`. Никаких оценок.

### З.8 ПРОДОЛЖАЙ С МЕСТА ОБРЫВА
Self-bootstrap (SELF_BOOTSTRAP.md) — git clone → make verify → проверено.
Каждая новая AI-сессия начинает с чтения AGENTS.md → POLYMATH_PROTOCOL.md
→ ADRs → и продолжает.

## Эмерджентность — гипотеза, не утверждение

«Эмерджентность» здесь — **проверяемая гипотеза**, а не результат. Что
доказано: лестница абляции B0→B3→EIR на 14 сценариях. Что не доказано:
превосходство на реальных workload'ах. См. `runtime/docs/EXPERIMENT_PLAN.md`.
