# HOLOS Agent v2.0 — голографический холон

Агент-холон с противогаллюцинационным контуром: отвечает только из корпуса,
каждое утверждение заземлено цитатой + Меркла-путём манифеста. Чего нет
в корпусе — честный статус «НЕ ЗНАЮ» / «ИСТИНА БЕЗ ТЕЛА», а не выдумка.
Собран по алгоритму корпуса «СУММАРНЫЕ ОТВЕТЫ НА ГАЛЛОГРАММУ_1/2.txt».

Формула корпуса:

```
Целое  = части + отношения + общий геном + манифест + правила проверки + история
Часть  = тело + кости + (геном, корень, индекс) + эскиз целого + соседи
Истина = то, что проходит суд: согласовано с геномом и доказуемо из манифеста
Эхо    = всё, что звучит как часть, но не может предъявить тройку
```

## Шесть органов (+ расширения)

| Орган    | Функция                                                                   |
| -------- | ------------------------------------------------------------------------- |
| ГЕНОМ    | конституция Г1–Г10, амендмент k-из-n подписей                             |
| МАНИФЕСТ | append-only, Merkle-корень = имя Целого                                   |
| ТЕЛО     | часть с носимой тройкой (геном, корень, индекс) + путь                    |
| ЭСКИЗ    | HRR-снапшот Целого пониженного разрешения (32-мерная циркулярная свёртка) |
| ДЫХАНИЕ  | VectorClock + ORSet (CRDT), слияние манифестов «ОДНО ДРУГОЕ НЕ ИСКЛЮЧАЕТ» |
| СУД      | вердикты: ЧАСТЬ / ЭХО / ЧУЖОЙ / ОСКОЛОК / ОТКАЗ                           |

Расширения: ПАМЯТЬ E/S/P/W/I (эпизодическая/семантическая/provenance/рабочая/
идентичность + реестр НЕ ЗНАЮ), PERSISTENCE (манифест на файле, кость К0),
ВЕБ-СЕНСОР (Evidence со статусом REPORTED — истины не создаёт).

## Инварианты

- **I1** append-only — прошлое не перезаписывается
- **I2** genome-immutable — геном не меняется без k подписей
- **I3** membership-arithmetic — принадлежность = хэш + корень + индекс, не вера
- **I4** echo-rejection — заявка без валидной тройки не допускается к сборке
- **I5** regeneration-bounded — восстановление только при ≥ k выживших

Кости честности К0–К6 воспроизведены в докстринге класса `Bones`.

## Честные границы

- **Корпус не входит в пакет** (default-deny, ADR-0002): приватный корпус
  подаётся при запуске; в дереве репо его нет и не должно быть.
- v1.0 (`holos.py`, selftest 33/33) — прямой предок, в пакет не включён.
- ВЕБ-СЕНСОР помечает находки статусом REPORTED — истины из поиска не создаёт
  (раздел 12 конституции корпуса).
