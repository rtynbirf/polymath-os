# polymath-agent v1.2.8 (линия Хронотоп · «Арсенал+Цепь»)

Автономный агент-полимат: **Субъект** (решения, память, свидетель) + **Тело**
(арсенал инструментов) + **Конституция** (инварианты). Один файл ядра, чистый
stdlib Python 3.9+, ноль внешних зависимостей. Самопроверка офлайн:
`python3 selftest.py` → **PASS 19/19**.

Линия соседей: `../polymath-agent-v3101/` (v3.10.1, линия СуперЗ · ЯДРО,
claim 33), `../polymath-agent-v3100/`, `../polymath-agent/` (v3.8.0 reference).
Здесь — **v1.2.8 «Арсенал+Цепь»**, головная версия отдельной линии «Хронотоп»,
доведённой кампанией цепей (10 живых огней) на локальной ollama qwen3:1.7b.
Полный отчёт хроники эпох I–VII («Хронотоп») и приборный слой хранятся в
приватном репо `polimat-task174`, `external/polymath_agent_v128/`.

## Быстрый старт

```bash
# офлайн, без LLM — 19 проб T01–T19 (запускать из каталога пакета):
python3 selftest.py

# живой огонь на локальной ollama (нативный /api/chat + JSON Schema):
python3 polymath_agent_v1.2.8.py --task "Создай hello.txt со строкой hi и проверь" \
    --brain ollama-native --model qwen3:1.7b --catalog tool_catalog.json --yes

# бюджет контекста/вывода (RAM-гейт: 4096 для 1.7b; 2560 для длинных цепей; 1536 для 4b):
export POLY_NUM_CTX=2560
export POLY_NUM_PREDICT=380
```

## Что внутри

- **Тело = арсенал.** `tool_catalog.json`: 2444 записи / 34 категории / 1601
  бинарь-кандидат (`polymat.arsenal/1.0`); на конкретном контейнере исполнимое
  подмножество подтверждает `shutil.which`. CatalogBridge: каталог декларирует —
  `which` подтверждает — Governor выпускает. `run_cli [EXEC]`: argv без shell,
  rlimit-песочница, дедуп-кэш, append-only аудит.
- **Субъект.** `--brain api | mock | ollama-native`. Нативный режим: `/api/chat`
  с `format=<JSON Schema>`, `think:false`; констрейнт-декодинг с
  maxLength-бюджетами (thought ≤280, пункты ≤120, ответ ≤600; act — ровно одно
  действие, maxItems 1). GBNF-эквивалент `decision_schema.gbnf` для llama.cpp.
- **Конституция.** Классы риска READ/WRITE/EXEC/NET/DESTRUCTIVE; изоляция путей;
  аудит с хеш-цепочкой; свидетель VERIFIED — механический: токен-факты ∨
  контентная сверка литералов критерия с артефактами на диске
  («(0 символов)» не свидетель).
- **$last_output.** Вывод последнего успешного действия-источника
  (exec/read/net/list) подставляется механически в `args` следующего действия:
  строка `"$last_output"` в args/stdin/content. Склейка «вывод команды → запись
  в файл» без семантического копирования. Чек записи переменную не трогает.

## Честные ограничения

- свидетель VERIFIED — механический (токен ∨ литерал в артефакте); семантический
  свидетель (NLI-эмбеддинги) — следующий шаг по лестнице;
- qwen3:1.7b проходит конвейер из 5 шагов с трансформацией (C1), но длинные цепи
  с промежуточными записями — за пределами модели при текущей сборке контекста;
  ядро готово принимать решения от более сильного мозга без изменения контракта;
- T12 требует `tool_catalog.json` в текущем каталоге — в пакете он лежит рядом;
  запускать `selftest.py` из каталога пакета.
