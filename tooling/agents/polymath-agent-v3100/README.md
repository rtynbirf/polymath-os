# polymath-agent v3.10.0 (линия СуперЗ · ЯДРО)

Автономный агент-полимат: Субъект (конституция, воля, память) +
Тело (арсенал инструментов) + Конституция (инварианты). Нулевые
внешние зависимости, чистый stdlib. Головная версия линии
`polymath-agent` (соседний `../polymath-agent/` — v3.8.0,
reference-реализация claim 28; здесь — головная v3.10.0).

**v3.10.0 — C5 GATE ANTI-VACUUM**: анти-вакуумное правило гейтов
стало механикой рантайма, а не дисциплиной прибора — вакуумный
отказ невыразим (`VacuousRefusalError`), каждый гейт COMMIT-контура
несёт именованные причины отказа и парных свидетелей
(`GATE_REGISTRY`: 11 отказных семейств, 51 пара honest+refusal),
мета-гейт T140 роняет selftest при удалении парной пробы. Плюс
наследие v3.9.0 (A.1 HMAC DOMAIN BINDING): `authorize_signing_key`
связан с активной эпохой RootEpochChain стандартным HMAC-SHA256,
ротация/отзыв корня инвалидируют неподтверждённые авторизации
(T137–T139).

## Как проверить

```bash
python3 tooling/agents/polymath-agent-v3100/selftest.py   # claim 32: 135/135
```

Selftest покрывает всё, что v3.8.0 (конституция — запреты/инварианты,
субъектный цикл намерение→шаг→свидетельство, порты доверия T100–T103,
переживание памяти через перезапуск), плюс T137–T139 (HMAC-связка
домена), T140–T141 (анти-вакуум гейтов C5) и усиленные
T64/T65/T115/T117/T120 (ассерт именованной причины). Рядом лежит
`tool_catalog.json` (2444 записи, 34 категории, 2444 уникальных
бинарей, формат `polymat.arsenal/1.0`) — с ним T12 «реальный арсенал»
= реальный PASS (2444/34), а не SKIP.
