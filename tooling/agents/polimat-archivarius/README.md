# POLIMAT-ARCHIVARIUS v2.1 — холон-агент из контекста владельца

Агент-холон, собранный из корпуса владельца: два архива «СУММАРНЫЕ ОТВЕТЫ
НА ГАЛЛОГРАММУ» (.txt + _1.txt с досье HOLOS, протоколом «Одно другое не
исключает», POLYMAT-HOLO, HHA) + КОНСТИТУЦИЯ_ХОЛОНА.md. Агент не «использует»
архитектуру из диалога — он **построен** из неё: целое для своих частей
корпуса, часть голографического Целого.

Формула генома v2: **387 content-addressed частей, корень `38f6d815…`**
(Merkle DAG, leaf = sha256(id+текст), дедупликация адресов сквозь все файлы).

## Пять органов (всё живёт в коде, pure stdlib)

| Орган    | Плоскость | Реализация                                                                                                                                                     |
| -------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ГЕНОМ    | L0        | корпус → части (id = sha256) → Merkle DAG → корень = «ДНК»                                                                                                     |
| ТЕЛО     | L5        | Рид–Соломон k=8 из n=12 (матрица Коши, MDS, поле Галуа GF(2^8)): любые 8 осколков восстанавливают геном, корень неизменен                                      |
| ДЫХАНИЕ  | L2        | gossip-CRDT (G-set): реплики рождаются со срезами (сектор «французского флага» + перекрытие), обмениваются дельтами, сходятся к одному общему корню без лидера |
| СУД      | L3        | эхо-детектор: тройка членства (адрес части + корень манифеста + путь Меркла); эхо не изгоняется — не допускается к сборке; trust scoring, карантин по порогу   |
| ПРОЕКЦИЯ | L2        | TF-IDF retrieval с русским стеммером; ядро-цикл из 5 фаз при каждом ответе; цитаты несут Merkle-доказательства                                                 |

Ядро-цикл холона (исполняется при каждом ответе):

```
слушать(gossip) -> слить(дельту)        # интерференция: поиск релевантных частей
сверить(корень, доказательства)        # истина: целостность генома
действовать(геном, адрес, проекция)    # автономия: синтез ответа
издать(свою дельту) -> разослать       # вклад в целое: ответ + доказательства
при(отказе) -> регенерировать          # заживление: k-из-n
```

## Инварианты

- **I1** адрес части уникален (дедупликация сквозь файлы — поймано selftest'ом)
- **I2** членство доказуемо арифметикой: тройка (геном, корень, путь Меркла)
- **I3** эхо-отсечение: заявка без валидной тройки не участвует в сборке
- **I4** регенерация ограничена: восстановление только при ≥ k живых осколков
- **I5** подмена содержания не проходит лист-хеш

## Самопроверка

```
python3 selftest.py    # 30/30 PASS: геном, Merkle+подмена, РС k-из-n
                       # + честный отказ, gossip-сходимость, суд (4 кейса),
                       # журнал, детерминизм геномезиса, self-scan секретов
```

## Команды (полный агент)

```
python3 polimat.py ingest    # геномезис: corpus/ -> части -> Merkle -> 12 осколков
python3 polimat.py status    # самочёт холона
python3 polimat.py search Q  # чистая проекция (без мозга)
python3 polimat.py prove ID  # доказательство принадлежности части
python3 polimat.py gossip    # дыхание: сходимость реплик
python3 polimat.py sud T     # суд: эхо-детектор
python3 polimat.py demo      # пять чудес (без LLM)
python3 polimat.py ask Q     # цикл холона: доказуемый ответ (мозг: z-ai chat)
```

`ask`/`chat` требуют утилиту `z-ai` (LLM + web_search как внешний контур —
внешние источники честно помечаются, доказательств не получают).
Остальные команды — pure stdlib, работают без сети.

## Санитизация корпуса

В досье `_1.txt` находились истёкшие presigned S3-URL с AWS-кредами
(`AWSAccessKeyId=ASIA…`, `Signature=…`, `x-amz-security-token=…`).
Перед публикацией значения query-параметров заменены на `REDACTED`
(6 замен, текст и структура не тронуты); self-scan секретов входит в
selftest (gitleaks-паттерны: ASIA/AKIA/ghp_/github_pat_/x-amz-token).

## Честная цена

- Retrieval — лёгкий TF-IDF со стеммером («тусклая проекция», не семантический поиск)
- Дыхание и Суд — однопроцессная симуляция органов (сеть настоящих холонов — следующий шаг)
- Рождение реплик — секторы, в сумме покрывающие геном: G-set CRDT не может
  собрать часть, которой нет ни у одной реплики (поймано полевым тестом)
- `ask` зависит от аккуратности LLM: цитаты проверяет суд генома, гомоглифы
  (кириллическая «а» в hex-id) приводятся к латинице до проверки
