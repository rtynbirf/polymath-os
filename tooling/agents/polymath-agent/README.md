# polymath-agent v3.8.0 (линия СуперZ)

Автономный агент-полимат: Субъект (конституция, воля, память) +
Тело (арсенал инструментов) + Конституция (инварианты). Нулевые
зависимости, чистый stdlib, работает с любым OpenAI-совместимым
бэкендом (`api`), нативным Ollama (`ollama-native`) или без LLM
(`mock`, selftest).

## Как проверить

```bash
python3 tooling/agents/polymath-agent/selftest.py   # claim 28: 130/130
```

Selftest покрывает: конституцию (запреты/инварианты), субъектный цикл
(намерение→шаг→свидетельство), порты доверия T100–T103 (отзыв корня,
подмена authorization_hash, псевдоротация, чужой чекпоинт-отпечаток —
все отклоняются), переживание памяти через перезапуск.

## Отношение к канону

Layer 2 (AI Workflows, MCP-native): агент понимает MCP-адаптеры из
`tooling/agents/mcp/` как внешние арсеналы Тела (флаг `--catalog`).
Ядро не требует их: `--selftest` замкнуто на stdlib.
