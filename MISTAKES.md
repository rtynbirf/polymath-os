Ошибка не считается закрытой по слову «исправлено» — только регрессионной проверкой, которая ловит повторение. ## СВОД УРОКОВ (компиляция, правило 31 дома)

- МО-К1. Счёт без источника — не счёт: два разных числа в одном теле = дрейф лица (базис — правило 25 дома).
- МО-К2. Номер правила — ключ: переиспользование номера = по ссылке открывается чужой закон (правило 40 дома).
- МО-К3. Ключ не живёт в диалоге: раскрытый токен отзывается в тот же такт, а не «потом».

## ЗАПИСИ

### МО-01 · 2026-11-22 · README: два счётчика тестов одновременно

- Симптом: README несёт «290» и «295» одновременно (raw, grep, 22.11.2026) — RUNTIME.
- Причина: числа вписывались в разное время из разных источников без триангуляции и метки свежести.
- Почему прежние проверки пропустили: гвард проверяет структуру и маркеры, а не согласованность чисел между секциями.
- Исправление: перековка автоматом число не лечит — нужна сверка фактическим прогоном `make verify` с публикацией результата.
- Статус: ОТКРЫТ — до прогона с независимым свидетельством.
- Evidence: raw.githubusercontent.com/rtynbirf/polymath-os/main/README.md, 22.11.2026.

### МО-02 · 2026-11-22 · центральный закон: блок 23–27 задвоен

- Симптом: rtynbirf/rtynbirf → AGENTS.md содержит две редакции блока 23–27 (строки 104–108 и 114–118) — RUNTIME.
- Причина: заход 3 (2026-11-20) вписан дважды; оставлено по правилу аддитивности.
- Последствия: ссылка «правило 25» открывает одну из двух редакций — по закону не определишь которую.
- Исправление: сворачивание — решение хозяина (аддитивность запрещает самовольное удаление); правило 40 дома запрещает новые переиспользования.
- Статус: ОТКРЫТ — ждёт явного слова хозяина.
- Evidence: blob-API AGENTS.md, blob-sha e50f95f, 22.11.2026.

### МО-03 · 2026-11-22 · polymath-multiagent: два разных списка правил 1–5

- Симптом: в polymath-multiagent/AGENTS.md номера 1–5 заняты двумя разными списками (правила журнала, строки 27–36; правила автоматов, строки 47–60), причём правило «Живое лицо» ошибочно названо «ПРАВИЛО 25» при собственном номере 5 — RUNTIME.

### МО-04 · 2026-11-22 · токен god-уровня многократно раскрыт в диалоге
