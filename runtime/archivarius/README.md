# АРХИВАРИУС — кооперативная память мультиагентов (v1.3.1)

Модуль Layer 5-окрестности: append-only память для нескольких агентов,
где целостность доказывается не одним механизмом, а согласованностью
нескольких независимых проекций. Нулевые зависимости, чистый stdlib.

## Что доказывается (84/84 selftest)

1. **Меркл-путь** — классическое доказательство включения записи.
2. **Цепь соседей** (v1.3) — двунаправленные хэши соседних срезов:
   выпадение или перестановка части видна любой из сторон.
3. **Подпись рождения** (v1.3) — геном агента → корень → срез → подпись:
   самозваный genesis и подмена родословной → ОСКОЛОК.
4. **Суд-согласованность** — «истина = согласованность трёх проекций»:
   вердикт судьи числами, не метафора (ЧАСТЬ / ОСКОЛОК / LoadError).
5. **Рид-Соломон** (v1.2) — восстановление утраченных частей из избыточных.
6. **Рефлексия** — агент может прочитать свою историю, не мутируя её.

## Отношение к SINGULYAR EIR

EIR хранит декреты и намерения в SQLite (`decree_log.py`, append-only,
hash-chained). АРХИВАРИУС решает смежную задачу для **мультиагентной**
среды: несколько агентов обмениваются артефактами так, что подделка
любой части доказуема соседями через независимые проекции, а утрата
частей лечится избыточностью. Версии линии: v1.0→v1.1→v1.2→v1.3.1
(журнал в досье-HTML), каждая версия прошла соседский аудит.
