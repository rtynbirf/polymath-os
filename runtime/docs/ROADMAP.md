# Дорожная карта — по условиям выхода (gates), а не по календарю

Статус: ✅ сделано и проверено тестами в этом архиве · 🟡 частично · ⬜ не начато. Календарные оценки намеренно не даются: сроки зависят от команды; важны условия выхода.

## Фаза 0 — Исполняемое ядро ✅ (v0.2)
Состояния, политика, проверка, внедрение сбоя. *Gate:* UNKNOWN не становится успехом.

## Фаза 1 — Надёжное локальное ядро ✅ (v0.3, этот архив)
SQLite-журнал, перезапуск → UNKNOWN → readback, реальная смерть процесса, схемы, failover, жёсткие ограничения, tri-state наблюдения, отпечатки вместо данных, лестница абляции.
*Gate (выполнен):* убийство процесса между эффектом и записью не приводит к дубликату или ложному успеху; повреждённый журнал не открывается; 36 тестов зелёные; мутационный контроль на ключевых ветках.
🟡 Остаётся: автоматизировать мутационные тесты; автоматизировать внешнюю контрольную точку.

## Фаза 2 — Контракты способностей ⬜
- Манифесты возможностей в версионируемых файлах (JSON), пересборка реестра из них.
- Набор тестов соответствия адаптера (conformance suite); минимум 2 независимые реализации одной возможности.
- Полный JSON Schema-валидатор (внешняя библиотека допустима для не-ядра).
*Gate:* два адаптера проходят один тест контракта; неподдерживаемое — отказ, а не «молча».

## Фаза 3 — Человеческий контроль и доступность ⬜
- Диалог уточнения намерения при неопределённости; объяснение «почему выбран адаптер».
- Выбор каналов ввода/вывода по заявленной пользователем способности (речь, клавиатура, брайль, переключатель) через платформенные API; тип инвалидности из поведения не выводится.
- Подпись решений человека (согласия), восстановление прав из подписанных записей.
*Gate:* тесты сохранения ограничений при смене каналов; тесты доступности на реальных вспомогательных технологиях.

## Фаза 4 — Реальный транспорт, отдельно от ядра ⬜
- Адаптер WebRTC data channel; сигнализация и идентичность проектируются отдельно; модель угроз, ключи, повтор, партиционирование сети.
- Различать: поставлено в очередь → отправлено → получено → подтверждено → (понято — только при явном свидетельстве).
*Gate:* независимый обзор безопасности; тесты потери/повтора/разрыва; матрица браузеров.

## Фаза 5 — Контролируемый эксперимент ⬜
Факторный дизайн 2⁴, независимые сценарии, hold-out, фаззинг точек отказа, сравнение с внешним движком надёжного исполнения — `EXPERIMENT_PLAN.md`.
*Gate:* предзаданный порог без роста нарушений; иначе гипотеза «эмерджентности» отвергается.

## Фаза 6 — Переносимость и федерация ⬜
Открытый формат обмена, экспорт/импорт у пользователя, конфликт-модель для нескольких устройств, отзыв прав, подпись релизов адаптеров.
*Gate:* чистый импорт во вторую реализацию сохраняет смысл задач и происхождение свидетельств.
